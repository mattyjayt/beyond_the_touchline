# Variable importance (duel study)

> **methodology demo: importance mirrors the generator (`duel-v2`); not football truth.** Generated by `uv run python -m app.analysis.duel_study --n 40000`.

- Method: standardised logistic regression on primitive inputs · grouped permutation importance (ROC AUC drop, 5 repeats) · ranks over several seeds.
- Seeds 2026–2030 · n = 40000 simulated duels per seed · mean test AUC 0.7802 against an oracle AUC of 0.7825 (scoring with the true p_beat). The model is at the ceiling, so the ranking says how the generator is built, nothing more.
- Groups pool near-duplicate inputs so they don't split credit. Derived terms (duel model terms, gaps, time-to-5 m, fatigue multipliers) are not fitted: `phy.speed_kmh_diff`, `phy.accel_idx_diff`, `phy.att_time_0_5m_s`, `phy.def_time_0_5m_s`, `phy.agility_idx_diff`, `phy.att_height_cm`, `phy.def_height_cm`, `pri.tech_gap`, `pri.att_passing`, `pri.att_finishing`, `pri.att_physical`, `pri.def_physical`, `pri.def_passing`, `ctx.att_fatigue_mult`, `ctx.def_fatigue_mult`, `duel.tech`, `duel.burst`, `duel.agil`, `duel.ctx`, `duel.p_recover`.
