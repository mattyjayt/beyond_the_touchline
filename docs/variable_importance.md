# Variable importance (duel study)

> **methodology demo: importance mirrors the generator (`duel-v2`); not football truth.** Generated by `uv run python -m app.analysis.duel_study --n 40000`.

- Method: standardised logistic regression · permutation importance (ROC AUC drop, 5 repeats); mutual information as a cross-check.
- Seed 2026 · n = 40000 simulated duels · test AUC 0.7799.
- Correlated variables share credit: a duel term (e.g. `duel.ctx`) absorbs much of its inputs' importance (e.g. stance), so read families together, not single ranks.
- Only engine-causal variables are ranked. Descriptive study variables (not ranked): `phy.att_height_cm`, `phy.def_height_cm`, `pri.att_passing`, `pri.att_finishing`, `pri.att_physical`, `pri.def_physical`, `pri.def_passing`, `duel.p_recover`.
